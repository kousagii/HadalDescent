# Hadal Descent

A 3D underwater exploration and marine research game made with Unity. Pilot a submarine from the Sunlight Zone into the deep ocean, discover marine species, document habitats, and earn Research Data Points (RDP) to upgrade your vessel for deeper expeditions.

## Features

- Explore five ocean zones: Sunlight, Twilight, Midnight, Abyss, and Hadal, with different depths, marine life, terrain, and visibility.
- Complete four minigames: **Capture and Focus**, **Reconstruction Scan**, **Environmental Cleanup**, and **Hazard Dodge**.
- Build a research bestiary with zone filters, discovery progress, interactive 3D specimens, real-world photographs, and detailed biological notes.
- Survey habitat landmarks and learn about their ecological roles through scientific fact cards.
- Navigate with sonar contacts, a depth display, objectives, a scanning reticle, and submarine lights.
- Spend RDP on hull, sonar, scanner, engine, lights, and utilities upgrades, with a rotatable 3D submarine preview in the shop.
- Verify your research through questions about discovered species before progressing into deeper zones. Zone access also depends on discovery progress and hull upgrades.
- Learn through an opening cinematic, guided tutorial, illustrated minigame instructions, and ocean facts during loading.
- Save and continue an expedition, and adjust audio, look sensitivity, and inverted camera pitch in settings.

## Development status

Work-in-progress prototype, version **0.1.0**, built with **Unity 6** and the **Universal Render Pipeline (URP)**. The project includes scenes for all five ocean zones, four core minigames, and a research verification activity. The demo shows Android touch controls; keyboard and mouse controls are also available in the Unity Editor. 
## Run from source

You need **Unity Hub**, **Unity Editor 6000.3.18f1**, and **Git with Git LFS**. To build for Android, install **Android Build Support**, including the Android SDK & NDK Tools and OpenJDK, for this editor version.

```sh
git lfs install
git clone https://github.com/kousagii/HadalDescent.git
cd HadalDescent
git lfs pull
```

1. In Unity Hub, choose **Add project from disk** and select the `HadalDescent` folder.
2. Open it with **6000.3.18f1** and let Unity finish importing assets and restoring packages.
3. Open `Assets/Scenes/SplashScreen.unity` and press **Play**.
4. Choose **New Game** to begin the opening sequence and tutorial, or **Continue Game** if you have a saved expedition.

To create an Android build, open **File > Build Profiles**, select or add an **Android** profile, and switch to that platform. Keep the configured scene order: `SplashScreen`, `MainMenu`, `SunlightZone`, `TwilightZone`, `MidnightZone`, `AbyssZone`, and `HadalZone`. Build into `Builds/Android`. Build outputs are ignored by Git.

## Controls

| Action | Touch / on-screen input | Keyboard / mouse input |
| --- | --- | --- |
| Move submarine | Drag the left joystick | WASD |
| Look around | Drag across the viewport | Drag with the mouse |
| Scan a nearby target | Camera button | F |
| Interact | Hand button | E |
| Toggle submarine lights | Light button | Click the light button |
| Open shop / bestiary | Cart / book button | Click the corresponding button |
| Pause / resume | Pause button, then Resume | Escape |
| Capture and Focus | Hold to raise the bar; release to lower it | Hold / release the mouse button |
| Reconstruction Scan | Tap a tile next to the empty space | Click an adjacent tile |
| Cleanup extraction | Move the joystick and press the claw / hand button | Use the on-screen controls |
| Cleanup sorting | Drag recovered items into the matching bins | Drag items with the mouse |
| Hazard Dodge | Swipe left / right or tap the lane controls | A / D or left / right arrow keys |
| Answer research questions / select menu options | Tap an option | Click an option |
